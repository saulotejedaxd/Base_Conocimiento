# Obsidian

Aplicación que almacena notas localmente como archivos Markdown y permite crear enlaces entre notas.

En este proyecto funciona como interfaz para:
- navegar `[[wikilinks]]`;
- visualizar Graph View;
- revisar contenido mantenido por un agente;
- mantener el Knowledge Graph como archivos legibles y portables.
