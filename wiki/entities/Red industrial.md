# Red industrial

Infraestructura y protocolos que permiten el intercambio de datos entre dispositivos de automatización.

El manual del In-Sight 3800 documenta soporte para protocolos industriales, incluyendo PROFINET y EtherNet/IP según configuración.

## Relaciones
Topología propuesta (`proposed`) para este proyecto —no una afirmación del manual Cognex sobre una instalación concreta—.

- [[PLC]]
- [[Robot industrial]]
- [[Sistema de visión]]
- [[HMI]]
