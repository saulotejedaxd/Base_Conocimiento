# Sistema experto

Sistema de razonamiento que organiza conocimiento explícito para apoyar una tarea especializada.

En este proyecto se modela mediante:
- [[Evidencia]]
- [[Reglas de producción]]
- [[Inferencia]]
- [[Hipótesis]] de [[Diagnóstico de fallas]]
- trazabilidad mediante [[Proveniencia]]

El resultado debe apoyar al usuario, no ocultar incertidumbre ni sustituir validación técnica.
