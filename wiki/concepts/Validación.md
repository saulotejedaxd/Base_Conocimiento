# Validación

Proceso de comprobar una [[Hipótesis]] con pruebas discriminantes y [[Evidencia]] adicional antes de aceptarla como [[Causa raíz]].

## Definición

La [[Validación]] incluye proponer pruebas que diferencien hipótesis alternativas, registrar resultados como [[Evidencia]] y recalcular hipótesis, según el [[Flujo de diagnóstico]].

## Relaciones

- evalúa → [[Hipótesis]];
- utiliza → [[Evidencia]] con [[Proveniencia]];
- se apoya en → [[Reglas de producción]] y su prueba discriminante (ver [[Plantilla de regla de diagnóstico]]);
- si tiene éxito, permite registrar → [[Causa raíz]];
- respeta → [[Seguridad funcional]] (nunca validar puenteando seguridades).
