# Seguridad funcional

Conjunto de funciones y medidas relacionadas con la reducción de riesgo y operación segura de sistemas automatizados.

Para robots industriales, ISO 10218-1:2025 establece requisitos de seguridad para el robot; la integración y aplicación se tratan en ISO 10218-2:2025.

## Restricción para el sistema experto

Una recomendación de diagnóstico nunca debe pedir:
- puentear una función de seguridad;
- ignorar un paro;
- rearmar automáticamente una condición que requiere intervención deliberada;
- modificar parámetros de seguridad sin evaluación de riesgos.
