# Knowledge Graph

Representación del conocimiento mediante entidades, conceptos y relaciones.

En este vault las relaciones se materializan principalmente como `[[wikilinks]]`. El Graph View de [[Obsidian]] permite visualizar la red creada por esos enlaces.

## Ejemplo de modelado (`proposed`, no afirmación de un equipo concreto)

[[Sistema de visión]] → genera → [[Evidencia]]

[[Evidencia]] → alimenta → [[Inferencia]]
