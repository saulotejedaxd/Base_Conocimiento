# Convenciones

- Idioma: español.
- Enlaces internos: `[[Nombre de página]]`.
- Nombres: singular, salvo nombres oficiales.
- No se usan números inventados.
- Los parámetros reales de una máquina se registran únicamente desde documentación, PLC, HMI, manual, medición o evidencia trazable.
- `verified`: respaldado por una fuente identificada.
- `proposed`: modelado o estructura conceptual creada para el proyecto.
- `requires_validation`: hipótesis o regla aún no confirmada.
- Las páginas de fuentes resumen; no reemplazan el documento original.
